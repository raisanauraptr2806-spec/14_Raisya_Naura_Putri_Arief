### A. Topik / Materi Utama
* **Building with AI & Managing Change with GitHub:** Mempelajari teknik *Prompt Engineering* untuk menyusun instruksi yang efektif kepada AI serta menggunakan Git dan GitHub untuk melacak perubahan kode dan kolaborasi proyek.

### B. Catatan & Poin Penting Pembelajaran
1. **Prompt Engineering:**
   * **Definisi:** Masukan atau instruksi tertulis yang diberikan kepada model AI agar menghasilkan jawaban yang tepat dan relevan.
   * **Struktur Prompt yang Baik:** Memiliki 4 pilar utama, yaitu *Role* (Peran), *Task* (Tugas), *Context* (Konteks), dan *Format* (Hasil keluaran).
   * **Pentingnya Konteks:** Memberikan latar belakang dan batasan yang spesifik membantu AI memahami kebutuhan kita secara akurat.

2. **Git & GitHub:**
   * **Git:** Sistem *version control* terdistribusi yang dirancang untuk melacak perubahan pada file secara lokal di komputer.
   * **GitHub:** Platform berbasis web untuk menyimpan repository Git secara online serta mendukung kolaborasi tim.
   * **Alur Kerja Git (*Git Workflow*):** 
     * *Working Directory* (folder kerja lokal) $\rightarrow$ *Staging Area* (`git add`) $\rightarrow$ *Repository / Commit* (`git commit`).

### C. Hasil Praktik
* Berhasil membuat repository GitHub dengan status *Public* sesuai ketentuan penugasan.
* Berhasil melakukan inisialisasi Git, melakukan *commit*, dan menyusun dokumentasi proyek sederhana (*Student Task Planner*).
* Menyusun file `README.md` secara rapi dan terstruktur yang memuat identitas, tujuan, serta catatan materi workshop.
